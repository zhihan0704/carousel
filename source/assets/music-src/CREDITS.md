## Changes made for this project

The unmodified source recording is 135.47 seconds long. For the embedded background track I kept the full composition, then:

1. Applied a 30 Hz high-pass filter and loudness normalisation to approximately −16.5 LUFS integrated, −2.4 dBFS true peak, for background listening.
2. Applied a 0.8 s fade-in at the beginning and a 1.7 s fade-out at the end (the source ends in near silence, so the loop returns to the intro without a hard click).
3. Encoded to MP3, 44.1 kHz stereo, 160 kbps, with ID3 title/artist/album/licence metadata.

The full track is embedded as a data URI in the single-file HTML; no network request is made at runtime.
