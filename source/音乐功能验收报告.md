- 授权核验：Wikimedia Commons 元数据明确标注 `LicenseShortName: CC BY 3.0`、`AttributionRequired: true`、`Copyrighted: true`；来源页和许可证全文已保存到 `assets/music-src/`。
- 音乐风格：3/4 拍华尔兹，实测节奏约 99.4 BPM；钟琴、钢片琴贯穿，法国号、低音提琴和弦乐铺底。它符合本场景需要的夜间游乐场/梦幻华尔兹氛围，也没有强烈鼓点或人声。

### 选择说明

优先检查了 CC0、公共领域和明确允许改编的录音。可搜索到的旋转木马/音乐盒主题候选里，部分只有 CC BY-NC-ND（不允许改编/不适合本项目），部分来源和录音版权不明确。最终没有找到同时满足“卡罗斯尔主题、音乐盒/钢片琴质感、3/4 华尔兹、可合法改编和嵌入”的 CC0/PD 录音，因此选择 **明确允许本项目使用和改编的 CC BY 3.0 录音**，并完整保留署名与许可证信息。没有使用来源不明的 MP3。

### 本页对音乐做的修改

- 30 Hz 高通、约 −16.5 LUFS 整体响度归一化与峰值控制（真峰值约 −2.4 dBFS），适合作为背景音乐。
- 0.8 秒开头淡入、1.7 秒结尾淡出；保留完整 135 秒曲目。
- 编码为 44.1 kHz 立体声 160 kbps MP3，写入 ID3 标题/作者/专辑/许可证注释。
- 通过 Base64 data URI 内嵌进单文件 HTML，不依赖外部音频服务器，不产生运行时音乐网络请求。

许可要求署名。最终 HTML 中同时保留了三处署名：

1. HTML 顶部版权注释；
2. 页面右下角音乐条的 ⓘ 版权信息面板（含曲名、作者、来源和 CC BY 3.0 链接）；
3. `README.md`、`assets/music-src/CREDITS.md`、`assets/music-src/LICENSE-CC-BY-3.0.txt` 和 MP3 ID3 注释。

## 控制与播放逻辑

- 位置：右下角，低矮的香槟金半透明胶囊控制条，高 54～56 px（移动端约 48 px），不覆盖旋转木马主体。
- 控件：播放/暂停、静音、音量滑杆（0–100%）、状态文字、播放时轻微起伏的四段金色电平、ⓘ 版权信息。
- 首次打开默认暂停，不自动播放；点击播放才开始，遵守浏览器自动播放策略。默认音量为 30%（目标区间 25–35%）。
- 播放时从 0 音量淡入 2 秒；暂停时在 1 秒内淡出，淡出完成后真正暂停。
- 只使用 HTML 中一个 `<audio>` 元素，设置 `loop`，没有创建额外 Audio 实例。
- 页面隐藏时暂停并清空音量，返回时自动恢复播放（若浏览器允许恢复）；恢复时重新淡入。
- 音乐加载/解码/播放失败时，控制条显示“音乐不可用”或“点击重试”，Three.js 场景继续运行。
- 控制条有键盘焦点样式；版权面板可以通过 Escape 关闭，打开时同步 `aria-expanded` 和 `aria-hidden`。

## 已知限制

- 自动化测试在 headless Chrome 中无法通过切换标签触发真实的 `visibilityState=hidden`；后台暂停/恢复逻辑用等价的隐藏状态事件验证通过。真实浏览器标签切换仍建议人工再点一次确认。
- 测试浏览器使用 `--mute-audio`，因此本报告验证的是媒体解码、播放时钟、音量状态和 UI，并未通过扬声器主观试听；音源是 Kevin MacLeod 已发布的正式录音，用户可在页面直接试听。
- 未在实体 iPhone/Safari 上测试；移动端使用 Chrome 触控/DPR 模拟。iOS 的媒体音量行为可能受系统限制，但播放/暂停、静音状态和界面更新使用标准 HTMLMediaElement API。
- 循环不是按小节做交叉淡化的 DJ loop；它保留原曲完整前奏/尾奏，并以淡入淡出和零电平端点消除爆音。若后续需要“无缝连续循环”，需要在音频编辑阶段重新裁剪一个 16/32 小节循环段。
